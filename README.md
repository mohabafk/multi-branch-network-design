# Multi-Branch Network Design

An academic network design project created using Cisco Packet Tracer
for a company with branches in Alexandria, Cairo, Aswan, and Port Said.

## Assignment Requirements
- Separate IP addressing for each branch.
- Capacity for up to 300 hosts in Cairo and 20 hosts in Aswan.
- At least two PCs with unique IP addresses per branch.
- One router connected to at least two switches per branch.
- A wireless access point with at least one connected device per branch.
- A dedicated DHCP server for each branch.
- DNS and web servers at the Alexandria branch.

2. Launch Cisco Packet Tracer.
3. Select File > Open.
4. Choose multi-branch-network.pkt to explore the network.
